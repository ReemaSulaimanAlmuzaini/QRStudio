# QR Studio

A simple and responsive QR code generator built with React.js.

## Features

- Generate QR codes for URLs
- Generate QR codes for text
- Generate Wi-Fi QR codes
- Generate email QR codes
- Generate phone QR codes
- Download generated QR codes
- Copy QR content
- QR generation history
- Responsive design

## Technologies

- React.js
- Vite
- Bootstrap
- JavaScript
- qrcode.react
- Browser LocalStorage

## Getting Started

### Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/qr-studio.git

Navigate to the project:

cd qr-studio

Install dependencies:

npm install

Run the development server:

npm run dev
